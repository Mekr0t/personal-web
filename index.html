VB Visualizer

Browser music visualizer — vanilla ES modules, Web Audio, Canvas

Constraint: Stays lightweight or it dies. Every feature that would have pulled in a model or a server got cut.

Turns a track into vertical video for short-form. Onset detection runs on spectral flux, lyrics sync from LRCLIB, and the whole thing stays a static page: no build step, nothing to install, nothing to host, 9:16 out. Built for my own music channel, which means it gets used every week and breaks in public. Several visual modes, rewritten a few times into a module-based architecture.

On the roll: green ticks are onsets. The black pen is the signal, flattened at the red line wherever it would have needed a model or a server; the grey dots are what got cut.

2026 · in progress

Prismatic Arena

Stats site — Next.js, Riot API, Docker (Postgres + Redis)

Constraint: No production API key yet, so the work is sequenced around it. Everything that can be finished without full match throughput gets finished first.

Match-history mining for Teamfight Tactics. An automated merger labels raw board states into named compositions, so tier lists assemble themselves instead of being hand-maintained. The labelling pass and the front end are being built out now; anything that depends on live match volume waits its turn.

On the roll: match data arrives in steps and plateaus at the red line, where the production key is missing. The grey dots are the throughput waiting on the other side.

no cloud API

2026 · bachelor thesis

Voice-controlled robotic arm

Python, OpenCV, local LLM, speech recognition, Dobot Magician

Constraint: No cloud API. Speech recognition, the language model and the vision pipeline all had to run on the machine sitting next to the arm.

Spoken instruction into a local language model, model output into arm motion, and computer vision (OpenCV) closing the loop on where the objects actually are. Fully local inference. The interesting failure mode was never the robot, it was the gap between what a person says and what a gripper can be told to do.

On the roll: each green tick is a spoken instruction. Blue is where the arm is told to go, black is where it actually is: it overshoots and settles as vision closes the loop. Everything stays between the red lines; the grey excursion is the cloud round trip it never makes.

the result

2026

Purged walk-forward backtester

Research pipeline — Python, pandas, historical crypto data

Constraint: No live capital, ever. The deliverable is a number you can trust, not a bot.

Built to answer one question honestly: does a signal survive when you stop leaking the future into it? The pipeline runs the same strategy twice, once with leakage intact and once with purged walk-forward splits, and the gap between the two curves is the actual result. Capital at risk: zero.

On the roll: the blue pen moves over to start where black does. Blue runs with leakage intact and climbs; black runs honest and stays flat. The shaded gap, measured in red at the end, is the result.
